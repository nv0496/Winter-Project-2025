Library Management System

Winter Project 2025

Project Description

This project is a Java console-based Library Management System developed as part of the Winter Project 2025.
The application helps in managing basic library operations such as maintaining book records and handling book issue and return processes through a menu-driven interface.

The project focuses on implementing core Java concepts in a practical and understandable way.

Features

Add books to the library

Display all available books

Search books by name or ID

Issue books to users

Return issued books

Prevents issuing books that are not available

Simple and user-friendly console interface

Technologies Used

Java

Java Development Kit (JDK 8 or above)

Console-based application

How to Run the Project
Requirements

Java JDK installed

Any Java IDE (VS Code, Eclipse, IntelliJ) or Command Prompt

Steps

Clone or download the repository

Open the project folder

Compile the Java files:

javac Main.java


Run the application:

java Main


(Replace Main with the actual main class name if different.)



Conclusion

This project demonstrates the use of object-oriented programming concepts in Java to build a basic management system.
It is suitable for academic purposes and can be extended further with advanced features.
